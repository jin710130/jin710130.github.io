隱私權政策 / Privacy Policy

← ResearchOS Laptop Mail

1. 適用範圍 / Scope

ResearchOS Laptop Mail 是使用者本人自用的工具，僅供其擁有者（r00724034@gmail.com）在自己的電腦上使用。
ResearchOS Laptop Mail is a personal tool used only by its owner (r00724034@gmail.com) on the owner's own computer.

2. 存取的 Google 資料 / Google data accessed

  • https://www.googleapis.com/auth/gmail.readonly：唯讀存取使用者本人的 Gmail 信件，用來找出並下載研究報告附件。 / Read-only access to the owner's own Gmail messages, used to find and download research-report attachments.
  • https://www.googleapis.com/auth/drive.metadata.readonly：唯讀存取使用者本人 Google 雲端硬碟的檔名與檔案 ID，不讀取檔案內容。 / Read-only access to file names and IDs in the owner's own Google Drive; file contents are not read.

本工具不會寄信、刪信、修改信件或修改雲端硬碟檔案。 / The tool never sends, deletes or modifies email, and never modifies Drive files.

3. 資料如何使用與儲存 / Use and storage

資料只用於整理使用者本人的研究報告，並只儲存在使用者本人的電腦與其 Google 雲端硬碟。授權權杖以 Windows 帳號加密後僅保存在使用者本機。
Data is used only to organize the owner's own research reports and is stored only on the owner's computer and the owner's own Google Drive. Authorization tokens are encrypted with the Windows account and kept only on the owner's computer.

4. 分享 / Sharing

不分享、不出售、不傳給任何第三方，也不用於廣告或訓練通用模型。
Data is not shared with, sold to, or transferred to any third party, and is not used for advertising or to train general-purpose models.

5. 撤銷與刪除 / Revocation and deletion

使用者可隨時在 Google 帳號的「第三方存取」頁面撤銷授權，並刪除本機上的權杖檔。 / The owner can revoke access at any time in the Google Account "third-party access" page and delete the local token file.
